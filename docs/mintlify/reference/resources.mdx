#### create()

```python
create(*, audio, state, questions, model='tazo-large', idempotency_key=None, filename=None, content_type=None)
```

Upload audio and wait for a typed decision.

* Parameters:

  * **audio** (*str*  *|*_PathLike_*\[*_str_*]* *|* *bytes*  *|*_BinaryIO_) – Path, bytes, or a binary stream. Streams are read from their current position; seekable streams are restored and never closed.

  * **state** (*str*  *|*_dict_*\[*_str_*,* *Any*_]_ *|* *list*_\[_*str*_]_) – Shared context as a string, object, or list of strings.

  * **questions** (*Mapping*_\[_*str*_,_ [*ChoiceQuestion*](<> "tazo.types.ChoiceQuestion")  *|*[*NoulQuestion*](<> "tazo.types.NoulQuestion")  *|*[*ChoiceQuestionParam*](<> "tazo.types.ChoiceQuestionParam")  *|*[*NoulQuestionParam*](<> "tazo.types.NoulQuestionParam")*]*) – Question-ID map of choice/noul dictionaries or typed models.

  * **model** (*str*) – Public model ID. Defaults to tazo-large.

  * **idempotency_key** (*str*  *|*_None_) – Retained operation key, or None to generate a new one. Every automatic retry reuses the same key and upload snapshot.

  * **filename** (*str*  *|*_None_) – Optional name for bytes or file objects.

  * **content_type** (*str*  *|*_None_) – Optional MIME type; otherwise inferred from filename.

* Returns:

  Typed result, including request_id and idempotency_key SDK metadata.

* Raises:

  * [**DecisionPendingError**](<> "tazo.errors.DecisionPendingError") – Work continues after the retry budget is exhausted.

  * [**TazoError**](<> "tazo.errors.TazoError") – Authentication, validation, transport, or service failure.

* Return type:

  [*DecisionResponse*](<> "tazo.types.DecisionResponse")

  * **questions** (*Mapping*_\[_*str*_,_ [*ChoiceQuestion*](<> "tazo.types.ChoiceQuestion")  *|*[*NoulQuestion*](<> "tazo.types.NoulQuestion")  *|*[*ChoiceQuestionParam*](<> "tazo.types.ChoiceQuestionParam")  *|*[*NoulQuestionParam*](<> "tazo.types.NoulQuestionParam")*]*) – Exactly one choice or noul question.

  * **model** (*str*) – Public model ID; the model’s advertised capabilities apply.

  * **audio_scope** (*Literal*_\[_*'turn'*_,_ *'chunk'*_]_) – chunk (default) evaluates new audio; turn evaluates cumulative audio.


Async counterpart of Decisions.create, with identical input and retry policy.

File reads run in a worker thread; HTTP uses native asynchronous I/O. Cancellation does not imply cancellation of accepted server-side work. Retain a caller-supplied key when cancellation recovery is required.
