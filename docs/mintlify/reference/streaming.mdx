Managed streaming sessions. No reconnect, replay, or unbounded application queues.

### StreamingSession

```python
class tazo.streaming.StreamingSession(url, credential, state)
```

Synchronous session; use as a context manager and iterate events in one thread.

Send audio from another thread while iterating to receive provisional updates. `commit` and `update` send control messages; consume the corresponding acknowledgement before sending the next turn. `finish` requests a graceful end; keep iterating until `session.closed`. Context exit always closes the socket.

* Parameters:

  * **url** (*str*)

  * **credential** (*str*)

  * **state** (*\_State*)

### AsyncStreamingSession

```python
class tazo.streaming.AsyncStreamingSession(url, credential, state)
```

Async context manager and event iterator. Use a concurrent audio-sending task.

No background reader is created. The websocket’s bounded receive queue supplies backpressure. One task may receive while another sends. Cancelled operations close the socket; accepted durable evaluations may still finish.

* Parameters:

  * **url** (*str*)

  * **credential** (*str*)
