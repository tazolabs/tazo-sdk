Public client configuration and connection ownership.

### Tazo

```python
class tazo.client.Tazo(*, api_key=None, base_url='https://api.tazolabs.com', timeout=Timeout(connect=5, read=65, write=30, pool=5), max_retries=2, operation_timeout=180, http_client=None)
```

Synchronous client for the four public Tazo operations.

* Parameters:

  * **api_key** (*str*  *|*_None_) – Bearer credential, or read TAZO_API_KEY. May be omitted for health.

  * **base_url** (*str*) – API origin, optionally with a proxy path prefix; no /v1 suffix.

  * **timeout** (*float*  *|*_httpx.Timeout_) – Per-network-phase timeout in seconds, or an httpx.Timeout.

  * **max_retries** (*int*) – Additional HTTP attempts after the first (default two).

  * **operation_timeout** (*float*) – HTTP retry budget in seconds (default 180). Each network phase is capped by the remaining budget. A synchronous in-flight request can outlast this budget across multiple network phases/body chunks.

  * **http_client** (*httpx.Client*  *|*_None_) – Optional caller-owned HTTPX client; the SDK will not close it.

Use as a context manager, or call close. Streaming sockets have their own context managers and must be closed before closing this client.

#### close()

```python
close()
```

Release the SDK-owned HTTP pool. Safe to call more than once.

* Return type:

  None

### AsyncTazo

```python
class tazo.client.AsyncTazo(*, api_key=None, base_url='https://api.tazolabs.com', timeout=Timeout(connect=5, read=65, write=30, pool=5), max_retries=2, operation_timeout=180, http_client=None)
```

Native async client with the same configuration as Tazo.

Await create, list, and check. Use async with for streaming sessions. operation_timeout also enforces an async deadline during each HTTP attempt. Supplied HTTPX clients remain caller-owned.

* Parameters:

  * **api_key** (*str*  *|*_None_)

  * **base_url** (*str*)

  * **timeout** (*float*  *|*_httpx.Timeout_)

  * **max_retries** (*int*)

  * **operation_timeout** (*float*)

  * **http_client** (*httpx.AsyncClient*  *|*_None_)

#### close()

```python
async close()
```

Release the SDK-owned HTTP pool.

* Return type:

  None

## WAV helper

### wav_chunks()

```python
tazo.wav_chunks(path, *, chunk_ms=100)
```

Yield raw mono 16 kHz PCM16 from a WAV, without headers or real-time pacing.

* Parameters:

  * **path** (*str*  *|*_PathLike_*\[*_str_*]*) – PCM16 WAV recording. Compressed WAV and other formats are rejected.

  * **chunk_ms** (*int*) – Chunk size from 1 to 200 milliseconds.

* Yields:

  Binary audio frames suitable for `session.send_audio`.

* Return type:

  *Iterator*\[bytes]
