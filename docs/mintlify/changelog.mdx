## Unreleased

- Add `sample_rate_hz` (8000 to 48000, default 16000) to `decisions.stream`, and accept
  any mono PCM16 WAV rate in `wav_chunks`. Add `wav_sample_rate`.
- Uploads accept any sample rate and common formats such as WAV and MP3.

## 0.1.2 — 2026-10-30

- Default sync and async streaming to `audio_scope="chunk"`.
- Accept a `None` turn-duration limit for continuous chunk streams; continue
  enforcing numeric limits and per-message size limits.
- Update the examples and reference for the current public API.

When upgrading, pass `audio_scope="turn"` explicitly if the final decision must
cover the complete recording. Chunk results cover the latest audio window.
The SDK continues to send mono 16 kHz PCM16. Uploads, health, and model discovery
are unchanged.

## 0.1.2rc1 — 2026-10-28

- Prepare a release candidate to verify publishing from the public SDK repository.
- Add public source and issue-tracker links to the package metadata.
- Keep the same SDK behavior as 0.1.1; the runtime version identifier changes.

This is a prerelease. Install its exact version when testing it; ordinary
installations continue to use the stable release.

## 0.1.1 — 2026-10-27

- Use PyPI installation instructions in the README and customer guides.
- Correct publication status and update the generated Python reference.
- SDK request and response behavior is unchanged.

## 0.1.0 — 2026-10-27

- Sync and async clients for decisions, streaming, models, and health.
- Typed responses, replayable audio uploads, retained operation keys, and bounded retries.
- Managed streaming sessions with explicit turns and no automatic audio replay.
- Public question types: choice and noul, subject to model capabilities.

Requires Python 3.11+ and targets Tazo API v1. This package is in beta; its Python
interface may change before 1.0. Additive response fields are retained.
