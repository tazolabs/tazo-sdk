## 0.1.1 — 2026-10-27

- Use PyPI installation instructions in the README and customer guides.
- Correct publication status and update the generated Python reference.
- SDK request and response behavior is unchanged.

## 0.1.0 — 2026-10-27

- Sync and async clients for decisions, streaming, models, and health.
- Typed responses, replayable audio uploads, retained operation keys, and bounded retries.
- Managed streaming sessions with explicit turns and no automatic audio replay.
- Public question types: choice and noul, subject to model capabilities.

Requires Python 3.11+ and targets Tazo API v1. This package is in beta; its Python
interface may change before 1.0. Additive response fields are retained.
